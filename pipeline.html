The τ-bench pipeline, step by step

A faithful re-implementation of sierra-research/tau-bench: the user-simulator LLM and the agent LLM take turns, the agent calls tools against a live database, and at the end the real reward is computed — by replaying the gold actions on a fresh DB and comparing the two database states. Every prompt and every output is shown verbatim.

The control flow (exactly as the repo does it)

env.reset()

① User speaks first

User-sim LLM is seeded with its system prompt + the hidden instruction and the line "Hi! How can I help you today?", then emits the first customer message. That string is the agent's first obs.

agent LLM

② Agent acts

System = policy wiki, with tools. It returns either a tool call or a respond. (If it returns a tool call, only the first one is taken — tool_calls[:1].)

env.step()

③ World reacts

respond → the user-sim LLM replies (and may say ###STOP###). tool → executed on the DB; the observation is fed back to the agent. The user is not involved on tool steps.

≤30 steps

④ Loop → reward

Repeat until ###STOP### or 30 steps. Then calculate_reward() runs.
